
# 🕵️‍♂️ Fake or Safe - Spot the AI-Generated Image Game

Fake or Safe is an interactive web-based game designed to test your ability to distinguish between real and AI-generated images. Built with React and Firebase, the game encourages players to sharpen their visual judgment in a fast-paced, engaging environment.

---

## 🔗 Live Demo

🌐 https://fake-or-safe.web.app/

---

## 🎮 How It Works

Players are shown a series of images and must decide whether each one is real or AI-generated. The faster and more accurate your decisions, the higher your score!

---

## ⚙️ Features

- 🧠 Real vs. AI-generated image challenge  
- 🔐 Firebase Authentication (Email/Password login)  
- 🏆 Score tracking and user-specific high scores  
- 📈 Performance feedback at the end of each round  
- 🎨 Responsive UI built with TailwindCSS  

---

## 🛠️ Tech Stack

- React + TypeScript + Vite  
- TailwindCSS for UI styling  
- Firebase Authentication  
- Firebase Firestore (for storing scores)  
- Custom hooks and modular component structure  

---
